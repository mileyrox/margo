Use the uploaded mobile money-app screens as the visual reference, not a file-folder metaphor. Favor a warm cream canvas, navy typography and primary actions, burgundy highlights, powder-blue information cards, olive savings accents, rounded white surfaces, serif display headings, and a compact mobile bottom navigation. The reference palette includes Imperial Blue `#011E48`, Olive Green `#6C712E`, Powder Blue `#B8D3E9`, Cream `#FFFDD0`, Burgundy `#48020C`, and Smoky Black `#100D08`.

**Why:** On November 3, 2026, the user explicitly asked to drop the folder concept and use the attached money-app screens as inspiration.

**How to apply:** Keep the overall page light and readable, use color for clear hierarchy, and avoid folder tabs, stacked file layers, and decorative circles.
