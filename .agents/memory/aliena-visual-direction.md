Use the supplied Margo mobile screens as the source of truth. Set the canvas to `#FBF6E4`, white cards with `#E8DFC4` borders, navy `#0B1F4B` for text and primary actions, secondary text `#4A5578`, burgundy `#5A0F1A` for alerts/over-budget states and the plus button, and olive `#6D712E` only for savings tags. Reserve `#C9DBEC` for progress fills on navy. Use Fraunces 600 for headings and DM Sans elsewhere; keep secondary text at least 13px and avoid gray, sage, khaki, and all-caps labels. Main screens use the seal-and-wordmark header, avatar-to-Settings, and the Home / Spending / + / Swaps / Gigs bottom nav. Onboarding is one Margo chat conversation with answers persisted in the user profile.

**Why:** The user supplied Margo screens and explicitly specified exact design tokens and a conversational setup flow on November 4, 2026.

**How to apply:** Follow these values across every Margo route and responsive state; do not copy sample names, products, or dollar amounts from the reference.
